## Edit the page

- `project-page/index.html`: content, authors, conference, resource links and BibTeX
- `project-page/style.css`: layout and typography
- `project-page/script.js`: gallery, figure zoom and citation copy
- `project-page/assets/`: original figures from the paper

The buildless static page requires no dependency installation. GitHub Actions publishes `project-page/` after changes to this directory or the Pages workflow. Pages uses the GitHub Actions source. The page is public and requires no login. Figure provenance is documented in `docs/PROJECT_PAGE_ASSETS.json`.
